Backup & Restore Data (JSON)

Ekspor seluruh Buku Resep, Database Bahan Baku, dan Riwayat ke file JSON agar aman saat berpindah perangkat atau membersihkan browser. Anda dapat memilih mode Gabung (Merge) atau Timpa Semua (Replace) saat memulihkan.

Privasi, PWA & Penyimpanan Lokal

Baking Calculator Pro menyimpan seluruh data secara lokal pada browser perangkat ini dan tidak mengirim data resep atau biaya Anda ke server eksternal.

Tentang Baking Calculator Pro

Versi 1.4.0

Baking Calculator Pro adalah aplikasi web statis untuk home baker, UMKM kue, dan bakery kecil. Dirancang agar ringan, presisi, dapat dijalankan secara lokal maupun melalui GitHub Pages tanpa akun dan tanpa biaya langganan.
